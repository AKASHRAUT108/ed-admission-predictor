# ED Admission Predictor

A full-stack application that predicts the probability of hospital admission for emergency department patients and supports bed planning decisions.

## Project Goal

Emergency departments face overcrowding. This project uses machine learning to predict, at the point of triage, whether a patient is likely to require admission. The prediction is displayed on a dashboard so that bed and staffing decisions can be made earlier.

**Disclaimer:** This system is built for learning and demonstration purposes only. It is not a clinical decision-support tool and must not be used for real medical decisions.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React (Vite) |
| Backend | Node.js + Express |
| ML | Python (scikit-learn / XGBoost) |
| Visualization | Recharts |
| Containerization | Docker + Docker Compose |
| Deployment | Vercel (frontend) + Render (backend) |
